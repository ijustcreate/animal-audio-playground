# Sample-media contract

The public repository treats `animals/` as a privacy boundary, not a general asset bucket.

Only these items are intended to be tracked:

- `_template/`: generic configuration examples with no visitor data;
- `sample-owl/`: a fictional animal, original SVG illustration, and deterministic synthesized WAV generated by `npm run sample:generate`;
- this contract.

Every real exhibit folder is ignored by default. That includes its images, field recordings, narration, videos, archives, visitor copies, timestamps, logs, and performer names.

## Adding local exhibit content

Copy `_template/` to a new folder and keep the folder name, `.animal.md`, and `.about.md` slug aligned. The app supports common image, audio, and video formats. Local media belongs on the exhibit machine or in an access-controlled asset system—not in this public repository.

Before using any real media, confirm all of the following:

1. You own it or have written permission for this exact use.
2. Every identifiable speaker has consented; a parent or guardian has approved recordings involving minors.
3. The file and metadata do not disclose a full name, age, school, location, or other identifying detail.
4. A retention and deletion policy exists for visitor recordings.
5. Public publishing is a separate, deliberate review—not an automatic consequence of adding content to the app.

## Generated sample

Run:

```powershell
npm run sample:generate
```

The command rewrites only:

- `sample-owl/sample-owl.image.svg`
- `sample-owl/audio/sample-owl-call.wav`

Both outputs are generated locally from source in `tools/generate-sample-media.mjs`. They contain no photographed subject, field recording, narration, name, or voice.

## Never commit

- `guest-recordings/` or its JSONL logs
- `archive/`
- recordings named with `read-by`, `from-`, ages, or visitor names
- raw microphone captures
- downloaded video or audio without explicit redistribution rights
- images with unclear provenance

`npm run check` enforces the current public allowlist after files are staged.
